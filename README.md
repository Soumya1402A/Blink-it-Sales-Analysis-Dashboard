Project Overview: This project analyzes Blinkit's grocery sales data using Power BI to uncover sales trends, customer preferences, outlet performance, and product category insights. The interactive dashboard enables stakeholders to monitor key business metrics and make data-driven decisions for improving sales and operational efficiency.

The main objectives of this project are:
-Analyze overall sales performance across different outlets.
-Identify top-performing product categories and outlet types.
-Understand the impact of outlet size and location on sales.
-Compare sales distribution across item categories.
-Provide interactive visualizations for business decision-making.
-Track key KPIs such as Total Sales, Average Sales, Number of Items, and Average Ratings.
